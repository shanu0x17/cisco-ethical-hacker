# Lab 07 – Exploring the Social Engineer Toolkit (SET)

## Objective

Understand how the Social Engineer Toolkit (SET) can be used to simulate social engineering attacks by launching SET, cloning a website, and capturing submitted credentials in a controlled lab environment. :contentReference[oaicite:0]{index=0}

---

## Environment

- Operating System: Kali Linux
- Platform: Cisco Ethical Hacker Virtual Lab
- Tool Used:
  - Social Engineer Toolkit (SET)

---

## Activities Performed

- Launched the Social Engineer Toolkit (SET).
- Explored the available social engineering attack modules.
- Selected the Website Attack Vectors module.
- Used the Credential Harvester attack method.
- Cloned the Instagram login page.
- Configured the local IP address to receive captured data.
- Observed incoming HTTP requests and submitted parameters.

---

## Tools Overview

| Tool | Purpose |
|------|---------|
| Social Engineer Toolkit (SET) | Framework for simulating social engineering attacks |
| Credential Harvester | Captures credentials submitted through cloned web pages |

---

## Key Observations

- SET provides multiple social engineering attack modules.
- The Credential Harvester successfully cloned the target login page.
- The cloned page accepted user input and forwarded requests to the local listener.
- Incoming HTTP requests and submitted form parameters were displayed in real time.
- The exercise demonstrated how phishing websites can collect user credentials when users interact with fake login pages.

## Key Learnings

- SET simplifies the creation of realistic phishing simulations.
- Credential Harvesting captures data submitted through cloned login pages.
- Website cloning is commonly used during authorized penetration tests to evaluate user awareness.
- Social engineering attacks target human behavior rather than technical vulnerabilities.
- Such techniques must only be performed in authorized environments.
